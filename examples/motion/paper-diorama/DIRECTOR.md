# 完整合影的纸艺景台

本例为叁笙原创工程，基于 AI 素材制作。Claude Opus 5.5 交付首稿后，当前 Agent 做了实际渲染、播放审片与定向返修；代码不是未经修改的 API 原样输出。

# 导演说明 · P1 合影立体纪念卡

## 结构（CSS3D，本地素材，没有外网依赖）
- **底页/纸台**：一块760×440的水平纸板，四周留白纸边，纸面上印的是草地下部。桌面上有一层柔和的接触阴影。
- **背板**：铰链在底页后边线（y=-6），角度a取0°（竖直）到90°（平扣在底页上）。正面是plate空草地，背面做成封面：source原合影加白框和"夏日草地 · 三人合影"。合拢后封面朝上，看上去就是一张完整封面。两面都设了backface-visibility:hidden，不会出现反面穿透。
- **合影立片**：直接用group-local原像素，346×407，按alpha bbox裁出，四向drop-shadow做白色模切纸边，所以脚边残留的草色读起来像纸边。立片底边带一条白色纸舌，**转轴就是底页z=420处的折线**，鞋底贴在这条线上。角度b取90°时立片向后平躺，盖在底页上。
- **与底座的连接**：立片背后左右各有一组风琴支架（x=±112），每组两段，每段长90。下端固定在底页z=300，上端连在立片背面120高的位置。中间折点每帧按两圆求交算出，取朝前的那个解；卡片合拢时两段纸都平躺在立片下面。支架两端和立片转轴都由同一个b推出来，人物只会绕折线立起，没有任何平移。
- **四株纸艺花草**：同样绕底页前缘各自的折线向后平躺、再立起，比人像晚一点出现。

## 时间线（9秒，render(t)是t对9取模的纯函数）
0–0.8s 成品停留 → 0.8–1.8s 花草和立片先收平，短句淡出 → 1.7–2.5s 背板扣下 → 2.5–3.2s 封面停半拍，镜头略俯 → 3.2–4.3s 背板打开 → 4.0–5.2s 立片立起，略过头一点再回位 → 4.8–6.4s 花草依次立起 → 5.6–6.8s 短句浮现、"存"字印章按下 → 6.8–9s 成品停留。t=0和t=9的状态完全相同。

## 防穿插、防重影、防裁切
- 立片高413，底页深440，转轴在z=420，所以向后平躺时整片都落在底页范围内，被背板完整盖住。
- **半开极值**：我算过几何关系。立片和背板如果同时转动，背板角度大约超过31°时两者就会相交。所以收的时候先收立片（1.0–1.8s），背板到1.7s才开始扣，那时立片已经基本平了；开的时候背板先打开，立片要等背板只剩约12°时才开始抬。
- 平躺的各层用不同的y值分开（底页0、支架-1、花-2、人-3、背板-6），避免共面闪烁。
- 镜头只随卡片的开合程度小幅俯仰（rotateX -20°到-31°）和转动（rotateY -8°到-2°），全片没有缩放和横向拉伸。按估算，开到最大时背板顶在y≈70左右，底页前缘在y≈565左右，人像组约380–400px高。实际数值请用`FILM_DIAGNOSTICS()`取各物件的边界框核对。

## 局限（如实列出）
- 以上画面数值都是按透视手算的，我还没看过真实渲染帧。人像高度和左侧文字到卡片的间距，需要渲染后用诊断数据再校一遍，可能要微调`#world`的平移量或perspective。
- 底页和平躺的立片，从上方看到的是图片的背面，画面是镜像的。底页印的是草地，镜像看不出来；立片平躺时被背板盖着，不会露出。
- 风琴支架被人像挡住了大半，只能从腿缝和侧面看到一点。
- 光照是固定的渐变和变暗层，不是实时投影。立片的接触阴影只随立起角度变浓或变淡。
- 浏览器对CSS3D中相交平面的排序在个别帧可能有边缘锯齿，需要按实际帧检查。


打包素材保留原尺寸，使用 WebP 压缩衍生；与官网原始 PNG 的像素可能略有差别。支点、裁切和时间线对应本图，不可只换图片沿用坐标。技术复跑不继承用户采用或平台上传结论。
