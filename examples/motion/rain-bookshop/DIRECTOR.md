# 雨夜书店

本例为叁笙原创工程，基于 AI 素材制作。Claude Opus 5.5 交付首稿后，当前 Agent 做了实际渲染、播放审片与定向返修；代码不是未经修改的 API 原样输出。

# 雨落在书店门前：导演说明

## 画面
- 整个画面就是 stage.png 这一张连续全景，铺满 1280×720（等比 0.766 缩放，没有裁切，也没有拼接）。镜头不动，不缩放，建筑也不晃。
- 画面里的大幅变化都来自风雨。光线保持原图的状态，只有地面水区那一块倒影会轻轻流动，整张图不会闪烁，也没有压暗。

## 风和雨（10 秒一个循环）
- 阵风的强度由一条周期函数控制，曲线是 0.5−0.5cos 再取三次方。远、中、近三层雨用同一条曲线，但起风时间依次晚一点（1.8 秒 / 3.0 秒 / 3.9 秒）。看起来是：后方的细雨先斜下来，随后近处几道更粗、更清楚的雨线横扫过去，最后风停回到小雨。
- 远雨约 760 道，细而淡，被书店房体的多边形挡住，所以它在房子后面。
- 中雨约 200 道，雨棚下方、橱窗和门前这块区域把它挡掉，棚下不会凭空下雨。
- 近雨最多 26 道，只有起风时才出现，风越大出现得越多，画在最前面。
- 雨线的位置都由固定种子的哈希算出：下落量乘以 10 秒正好是整数个画面高度；风造成的横向偏移，用一张预先算好、首尾相接的积分表。所以首尾无缝，可以按任意顺序调用渲染，也不会累积状态，没有在每帧调用 Math.random。

## 因果链：檐口积水 → 滴落 → 水环 → 倒影被扰动
- 雨棚的波浪边上锚定了 4 个滴水点，左侧街巷的檐口另有 1 个。每个点的周期是 2、2.5、3.33 或 5 秒，都能整除 10 秒。
- 一个周期里，水珠先在檐边慢慢长大，然后按重力加速落下，落到正下方对应的石板上，产生两圈扩散的椭圆水环，同时溅起 4 个小水点。水环持续约 2.2 秒，所以每个落点都有足够时间看清。
- 倒影区域约为 x 440–1080、y 545–720，在这里按行重新取样原图，并做横向波动。波动幅度来自附近的水环能量（按高度距离做高斯衰减），所以水滴落下后，窗灯的暖色倒影会被搅乱，随后再慢慢恢复。边缘做了羽化，让它自然融进周围。

## 已知的局限
- 房体和雨棚下方的遮挡范围是手工勾的多边形，不是像素级的蒙版，屋顶边缘附近会有几像素的误差。
- 地面倒影是对原图像素做横向错位，不是真实的反射，没有分开计算的真实水面。
- 画面里没有文字。字体只是按要求加载，加载完成才算准备就绪。
- 素材路径先读 assets/stage.png，读不到再读同目录下的 stage.png。
- `FILM_DIAGNOSTICS()` 会返回当前阶段、遮挡多边形、滴水锚点、倒影区域，以及当前正在扩散的水环。

打包素材保留原尺寸，使用 WebP 压缩衍生；与官网原始 PNG 的像素可能略有差别。支点、裁切和时间线对应本图，不可只换图片沿用坐标。技术复跑不继承用户采用或平台上传结论。
