# 信息图（3:4 或 9:16）

场景 id `info`，格式 `infographic`。图型决策见 [figure-types](../lib/figure-types.md)，文字见 [text-budget](../lib/text-budget.md)。结构几何在 `structures/structures.json`（24 种，如 flow、compare、quadrant、pyramid、iceberg、funnel、cycle、timeline、mindmap）。

先应用 [内容取舍与评审](../editorial-review.md)：读者与沟通目标先于画风默认值；覆盖与字号按本用途验收。

## 两种信息图

- **单结构图**（默认）：一张图只讲一个结构，一个版式讲一件事。几何写在提示词前面，节点数写死；副标题明确写「不是一步，不编号」这类防误读句；矩阵逐格写明每个象限放什么，否则模型会放错格。
- **多模块干货图**（选购、避坑、全攻略类，一图装多块）：由 4–7 个有功能的模块拼成，每个模块只有一个任务，原型见下节。规则：一个主导模块占约三分之一，其余等级分明；每个模块 ≤ 5 行；全图文字总量走「底图加程序排字」，不让模型写整张表；缩到手机宽度最小字仍 ≥ 12 px 等效。

## 高密度模块原型

每个模块一个任务；同一张图里同类模块最多一个。

| 模块 | 任务 | 骨架 | 上限 |
|---|---|---|---|
| 核心结论 | 一句话告诉读者结论 | 大字判断句 + 一行依据 | 1 句 ≤ 20 字，依据 ≤ 24 字 |
| 对比表 | 几个选项在几个维度上比 | 行是选项、列是维度，最优格高亮 | 3–4 行 × 2–4 列，每格 ≤ 6 字 |
| 步骤 | 照着做的先后顺序 | 编号竖排或横排箭头 | 3–5 步，每步 ≤ 14 字 |
| 避坑 | 常见错误和正确做法 | 错 / 对成对，红叉绿勾 | 2–4 对，每条 ≤ 14 字 |
| 数据 | 一个或几个关键数 | 大数字 + 单位 + 比较基准 | 1–3 个数，每个带一行 ≤ 12 字说明 |
| 清单 | 要准备或要检查的东西 | 打勾列表，每项一个小图标 | 4–6 项，每项 ≤ 10 字 |
| 行动 | 看完马上能做的一件事 | 底部横条，一句动词开头的话 | 1 句 ≤ 20 字 |

三套常见拼法（3:4 竖版，从上到下；百分比是大约占的画面高度）：

| 类型 | 拼法 |
|---|---|
| 选购 | 核心结论 15% → **对比表 35%（主导）** → 避坑 20% → 清单 18% → 行动 12% |
| 避坑 | 核心结论 15% → **避坑 35%（主导）** → 数据 15% → 步骤 23% → 行动 12% |
| 全攻略 | 核心结论 12% → **步骤 32%（主导）** → 清单 18% → 避坑 18% → 数据 10% → 行动 10% |

模块之间用留白或细分隔线分开，不加装饰性边框；每个模块的小标题直接写它回答的问题（「哪款适合新手」），不写模块名（「对比表」）。

## 流程

1. 读内容，写一句学习目标：读者看完要能做到什么。
2. 价值门式取舍：抽出关系和要点，不照搬全文。
3. 按关系类型选版式（单结构）或选模块组合（干货图）。
4. 冻结文字清单；带数字的信息图默认「留白底图 + 程序排字」。
5. 出图，逐字核对，按 post-checks 验收；底部常多出一行宣传小字，属可接受的小瑕疵，错字必须重出。

## 要避开的

提示词里不写真实品牌名当标签（模型会画出苹果标、窗格标），改写成「路线甲/乙/丙」，并写明「设备用通用图标，背面无品牌标志」；不在图里写图型标题；主导模块之外的单个模块占画面超过约 25%（会和主导模块抢焦点）。
