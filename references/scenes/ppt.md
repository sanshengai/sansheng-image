# PPT（整页图片，16:9）

场景 id `ppt`，格式 `ppt`。页型、规格卡、节奏、备注、改字见 [ppt-pages](../lib/ppt-pages.md)。要可编辑文件时用 `sb.py pptx --mode illustration`。

## 目的

屏幕上就是这一页，一眼看出讲者要说的核心主旨。主标题是一句整句结论，不是话题词。

## 流程

```
读文 → 阅读模式与受众 → 论点台账 → 页预算 → 幽灵稿（停一次）
  → 页型匹配 → 页规格卡 → 3 张样张并锁风格块 → 批量出图 → 检查返修
```

1. **阅读模式（一等参数）。** 用户没说就按场景推：上台、讲课、直播 → 演讲式；公众号、小红书、群里转发、留存 → 阅读式；其余 → 讲读兼顾（默认）。三档的每页字数见 [text-budget](../lib/text-budget.md)。目标动作也要推：告知、说服、决策、教学、汇报等，「决策」型必须有明确请求、选项、判据。
2. **论点台账。** 3000 字内不必切块；更长按标题切成 2000–3000 字，每块抽台账再合并。每条一行：编号、一句完整断言、级别（总论点/支柱/分论点）、类型、证据原子（数据点带单位、例子、机制、引文，各带原文位置）、优先级（必须/应该/可有可无）。整理成金字塔：1 个总论点、3–5 根支柱、每根下 2–4 条分论点。
3. **材料偏离度。** 贴近原文 / 平衡（默认）/ 自由。无论哪档，事实只来自原文，不借机引入外部事实或数字。
4. **页预算（页数由论点数推，字数只做体检）：**
   - 入选论点：演讲式只留「必须」，其余留「必须」加「应该」；「可有可无」阅读式入附录（附录不超过主线约 20%），其余舍弃。
   - 每条入选分论点默认 1 页；证据类型不兼容、压缩后仍超文字预算、或数据表超过约 6 行 × 4 列时拆成 2 页。
   - 结构页：封面加结尾 2 页；议程页 1（支柱 ≥ 4 或核心页 ≥ 10）；摘要页 1（非演讲式且核心页 ≥ 8，放第 2 页）；章节过渡页每章 1（核心页 ≥ 18，否则不加，改用页首进度条）。
   - 体检：每个核心页承载的源文字数 r = 字数 ÷ 核心页数，参考区间演讲式 500–900、讲读兼顾 350–600、阅读式 250–450；r 超出只回头查原因，不为凑区间硬改页数。
   - **上限 28 页（单卷主线）**：超过依次把「应该」降级进附录，仍太多则分卷：先出 8–12 页总览卷，再每根支柱一卷。
   - 用户给了页数或时长就以用户为准：页数少了依次删可有可无、合并同支柱相邻分论点、删议程与章节页、再删摘要页；页数多了先拆证据最重的分论点，不补装饰页；演讲式时长按每页约 1 分钟作上限参考。
5. **幽灵稿。** 只写每页的断言标题，通读：纵向每页内容都支撑本页标题，横向连读标题自成完整故事。给用户看这一版再出图，这是默认唯一的确认点（计划卡就是这一版幽灵稿；用户说「直接出」或自动流程调用时跳过，但计划卡照样存成 `plan-card.md`）。
6. **页型匹配与节奏。** 按 ppt-pages 的决策顺序和节奏规则。
7. **页规格卡。** 逐页一张，`rendered_text` 是唯一文字真源；文字承载方式逐页声明；数据图先用代码画成真图当素材。
8. **样张与锁。** 先出 3 张（封面、最复杂的内容页、最简单的内容页），过目通过后锁定风格块再批量；第一张内容页当后续页的参考图。
9. **检查与返修。** [post-checks](../lib/post-checks.md) 加整套项：只读标题连读成故事、页型节奏、台账覆盖（每个「必须」论点至少一页，没有孤儿页）、画面数字都能在原文找到。

## 样例推演（示意，非实测，回测前不当承诺）

| 源文 | 演讲式 | 讲读兼顾 | 阅读式 |
|---|---|---|---|
| 3,000 字 | 约 8–10 页 | 约 10–12 页 | 约 10–12 页 |
| 5,000 字 | 约 11–12 页 | 约 16–18 页 | 约 17–19 页 |
| 10,000 字 | 约 13–16 页 | 约 17–20 页 | 约 20–24 页 |
| 30,000 字 | 约 20–24 页 | 约 28–30 页，越上限须降级或分卷 | 须总览卷加分卷 |

## 检查

`python3 scripts/sb.py deck budget 台账.json --mode talk-read --chars 5000 [--pages N | --minutes M]` 按台账算页预算（结果带 `calibrated: false`）；`python3 scripts/sb.py deck check 页规格卡.json --mode talk-read` 检查整套规格卡（文字真源、禁渲染、标题与正文字数、必须保留、承载方式、页型相邻与密度节奏）。`stylebook.deck.check_prompt` 检查出图提示词逐字包含 `rendered_text` 且不夹带规格卡之外的可见文字。

公式与文字预算尚未用真实稿件回测，回测前以「建议值」对待。
