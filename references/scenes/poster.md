# 场景：海报

海报只有一个任务：**远看一眼认得出主视觉和标题，走近才读时间、地点。** 它和封面、插图的区别不在尺寸，而在这四点：

1. **远看、近看两层**：三米外只看得到主视觉和主标题；时间、地点、二维码属于近看层，字小但必须一字不错。
2. **一个焦点、一句话**：只有一个主视觉；主标题不超过 8 个汉字，副题不超过 16 个汉字。
3. **信息零错**：日期、地点、价格、网址只用用户给的信息，缺了就不放，**不编示例日期**。
4. **行动位**：活动和产品海报给二维码或报名方式留位置；用户没给二维码图就只留空位。

选题判据：**画一个能撑住画面的局部，不画全景。** 一扇漏窗、一段器口、一块刺绣，比一整座园林更像海报。计划卡的「画面」一栏写不出单一局部时，先收窄。文旅长卷（C102）例外：它本来就是长卷，但每一段只放资料卡里的元素。

## 尺寸（看板与计划卡显示 label）

| 格式 | 显示 | 说明 |
|---|---|---|
| `poster-9x16` | 9:16（朋友圈 · 手机竖屏 · 电梯屏） | 数字海报首选 |
| `poster-elevator` | 3:4（电梯框架海报 42.4×57cm） | 印刷 |
| `poster-a` | 1:1.41（A3 / A2 打印店常规纸） | 印刷 |
| `poster-5x7` | 5:7（50×70cm 标准印刷海报） | 印刷 |
| `poster-2x3` | 2:3（60×90cm 大幅海报 · 展板） | 印刷 |
| `poster-16x9` | 16:9（会场大屏 · 横版展示屏） | 唯一横版 |
| `poster-custom` | 自定义（输入宽 × 高 cm 与 dpi） | 清单写 `size_cm: [w, h]` 与 `dpi` |

印刷尺寸超出生图上限（最长边 3840 像素），本期导出为屏幕预览像素，并在交付时说明「印刷需放大，近看会软」；不把预览图说成可直接付印。印刷放大、出血与 PDF 导出在后续版本。易拉宝等比例超过 3:1 的尺寸不支持。

## 版式（清单字段 `poster_layout`）

| id | 名称 | 适合 |
|---|---|---|
| `vertical-title` | 竖排题签 | 东方编辑、器物、园林 |
| `sky-title` | 天头标题 | 通用；所有画风默认可用 |
| `corner-embrace` | 角落环抱 | 纸景、意境型 |
| `big-shape-band` | 大形出画 + 底部信息带 | 活动、手作工坊 |
| `axis` | 中轴对称 | 展览、演出；所有画风默认可用 |
| `type-led` | 大字主导 | 大字报、人物编辑海报 |
| `magazine-scroll` | 杂志栏 + S 形长卷 | 文旅长卷专用 |

每个画风在合同 `recipe.poster_layouts` 登记 2–3 种推荐版式；没登记的画风只能用 `sky-title` 和 `axis`。版式和格式、信息量档位不兼容时 `plan` 会报错并列出可选项。各版式的精确排字参考坐标在 `layouts/layouts.json` 的 `zones`；overlay 条目缺 `box` 时按版式补齐。

## 信息量档位（`poster_info`）

| 档位 | 文字 | 文字方式 |
|---|---|---|
| `mood` 意境型 | 主标题 + 一句副题，可选 1–2 行短句 | 主标题原生书写，其余精确排字 |
| `event` 活动型 | 加时间、地点、主办、二维码位 | 时间、地点、二维码一律精确排字 |
| `product` 产品 / 课程型 | 卖点不超过 3 条 + 行动入口 | 同活动型 |
| `travel` 文旅型 | 年份、印章、中英地名、简介、总结短句 | 仅 C102；印章程序生成 |

海报格式默认 `hybrid`：主标题由模型原生写（保留字与画面一体的质感），其余条目 `render: overlay` 精确排字。原生标题写错时重试一次；仍然错，就把标题降级为精确排字（宋体或楷体），并在计划卡标注「标题已降级」。竖排、印章与字体写法见 [text.md](../text.md)。

## 适合海报的画风

新画风：C100 青釉园林（克制）、C101 纸景微缩（意境）、C102 文旅长卷（丰盛，城市与家乡，见 [place-poster.md](place-poster.md)）、C103 圆域人物（时尚编辑人物，只用竖版与方形）。其余画风以合同 `uses` 是否含「海报」为准；未勾的不要硬用。

C103 选一种圆形手法（`variant`：light-cut 光落成界 / dual-glass 两界之间 / lens 折光之间 / mirror 另一种我）；一张图只用一种。人物默认虚构；用户上传本人照片时走 [consistency.md](../consistency.md) 的身份参考，并确认照片属于本人或已授权；不按姓名生成真实公众人物的肖像。

## 示例 brief

```json
{
  "version": 1, "scene": "poster", "style": "C100", "format": "poster-9x16",
  "poster_layout": "vertical-title", "poster_info": "mood",
  "reason": "竹编局部撑住画面，竖排题字留白安静",
  "items": [{
    "position": "cover", "message": "手作竹编展的气质",
    "visual": "一段竹编从右下进入，左侧大片暖白留白",
    "text": {"mode": "hybrid", "items": [
      {"render": "native", "role": "title", "text": "篾间"},
      {"render": "overlay", "role": "subtitle", "text": "一根竹，编出四季", "direction": "vertical"}
    ]}
  }]
}
```

## 交付前看图

除 [qa.md](../qa.md) 的通用项外，海报逐张再看：缩到 15% 宽度时标题和主视觉是否仍可辨；是否只有一个焦点；所有文字逐字比对，日期地点零容忍；版式留白区里有没有杂物；印刷格式四边 3mm 内有没有文字；画风专项（C101 人物尺度、C102 地标与资料卡一致、C103 镜像与折射合理）。

返修优先用合同 `qa.fix_phrases` 里的局部话术，先说保留什么，再说只改什么。
