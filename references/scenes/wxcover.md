# 公众号封面（含系列封面、X 版）

场景 id `wxcover`。格式 `wechat-cover-square`（方形母版）、`wechat-cover-head`（2.35:1）、`x-image`（16:9）。尺寸与安全区见 [platform-specs](../lib/platform-specs.md)，文字规则见 [text-budget](../lib/text-budget.md)，出图后检查见 [post-checks](../lib/post-checks.md)。

## 目的

一秒抓住人，让人觉得这是一篇高质量的文章。画面说一半，字说一半：一个具象主体占画面大头，标题放在上方或左侧留白处。

## 流程

1. **读文章，写主旨卡。** 四行：
   - **主旨**：一句话回答「读完读者带走什么」。
   - **主副标题与来源**：主标题 4–8 字，副标题 8–14 字；每条标出来源——原文某句的压缩、文章标题的改写，或原文里的关键词。不凭空增加数字、人物、结论（`plan` 会拦下原文里找不到的数字、引语、英文专名）。
   - **副标题的作用（三选一）**：交代对象（这是谁的、关于什么）、点出结论（读完知道什么）、给出证据（一个数或一个事实）。只做一件事，不和主标题重复。
   - **呼应句**：「画面里的___，对应标题里的___」。写不出这一句，说明隐喻物没选对，回到第 2 步。
2. **封面简报卡（随计划卡确认）。** 主标题、副标题各给 2 个候选，并排写来源和副标题作用，标出推荐；用户不挑就用推荐的。
3. **论点 → 隐喻物 → 构图。** 先把论点翻成一个动作或关系（打开、穿过、筛掉、对准、埋下、天平倾斜），再找一个具象物件承载它（钥匙、门、天平、齿轮、一盏灯、一条路），最后选构图类型。主体形成明确焦点，面积服从文字与实际裁切，不设统一占比；不堆多个图标；不用机器人、大脑、电路板、火箭这类烂大街符号。
4. **选构图类型**（6 类，选一类）：
   - 居中主体：一个物件居中，标题在上或下，最稳；
   - 左文右图：标题在左、主体在右，两者都在居中方形之内（C77、C90 封面的默认版式；清单写 `"layout": {"text_zone": "top", "hero_zone": "bottom"}` 可改成上文下图）；
   - 全幅场景加一句话：整幅氛围，标题落在天空或留白处；
   - 大字压顶：标题本身是主角，画面只做衬托；
   - 对比分屏：一条斜线把画面分成两半，表达前后或两种选择；
   - 物件特写：一件物品的静物特写，质感为主。
5. **选文字档位，反推留白。** 按实际文字行数与目标字号安排干净的文字区；30% / 40% / 50% 只能作试排起点，不与主体面积叠加成硬约束。
6. **选画风。** 用户有码用码；没有时先按读者、题材与气质选候选；用途默认只是回退，不自动压过成人专业、儿童学习等使用情境。系列文章用同一个系列封面画风（如 C90 深色系列封面）并锁修订号；写作 Skill 里封面可以单独选画风（`cover.own_style`），正文仍锁一个画风。

## 出图

- 默认先出方形母版，标题、副标题和主体都留在方形里，四边留 12% 以上；再把母版当参考图横向扩成 2.35:1，只延续两侧背景。会话列表和转发卡片显示的是方形，直接出横图常把标题裁断。
- 例外：C77、C90 左文右图且都落在居中方形内，直接出 2.35:1，不走方形扩图（扩图会把内容缩进中间）；方形版和 X 的 16:9（`x-image`，1200×675）各单独再出一张，不从横版裁。
- 标题按画风气质写：水墨配「云海听松」，黏土配「小小早餐铺」，赛博配「夜城漫步」。不画方框和边框。
- 高级感靠克制：2–3 色、大留白、半色调或纸张颗粒、负形，不靠发光和渐变。

`cover-check` 的黑底高对比阈值仅支持显式 `--style S02`，其他画风不输出假边距；方形裁切仍须实际看图。

私有样式 S02 的方形优先流程（含 `cover-flow` 命令与方形预检）见 [cover-flow.md](../cover-flow.md)。

## 验收

- **360 px 宽能读**：缩到 360 px 宽，主副标题都读得清；缩到 46 px 方形缩略图仍认得出主体。
- **遮图测试**：遮住画面只看字，仍能识别文章的对象或核心判断；不要求把全文结论塞进标题。
- **遮字测试**：遮住所有字只看画面，只剩一个视觉焦点，且能看出它和标题在说同一件事（对上主旨卡的呼应句）。
- 标题逐字核对；2.35:1 的中间 1:1 区域里标题和主体完整。

## 推荐画风

封面向画风：C74 丝网印海报、C75 暖纸克制双色、C76 杂志编辑封面、C77 叁笙深空、C90 深色系列封面；其余适合封面的画风照常可用，配方是同一套构图。
