# 出图配方：每类图怎么排、写多少字

写 brief 之前读这一页。它是 [scene-playbook.md](scene-playbook.md) 的落地版：页序、图型、字数都按这里定，Agent 不另起炉灶。来源是 2026-10 的试点（3 个画风、约 110 张，作者逐张确认）和公开做法调研（宝玉 baoyu-skills、Napkin、Gamma、xiaohongshu-card 等，只学结构）。

## 0 先给用户一张计划卡

读完内容后列一张表，每张图一行：对应段落、判断句标题、图型（附一个备选）、横或竖、图上全部文字。用户回「好」或只改一行就出图；用户只说「直接出」时跳过确认。用户只需要给内容，张数、比例、图型、文字都由 Agent 按本页补齐，不逐项追问。

图上的数字和比例写进计划卡前先自己算一遍。出图后的逐字核对只能查出「画错」，查不出「写错」。

## 1 公众号封面

- 先出方形母版（`wechat-cover-square`），标题、副标题和主体都留在方形里，四边留 12% 以上；再把母版当参考图横向扩成 2.35:1（`wechat-cover-head`），只延续两侧背景。会话列表和转发卡片显示的是方形，直接出横图常把标题裁断。
- 例外：C77、C90 封面默认左文右图（清单 `layout` 可改成上文下图，居中方形窄时更稳），标题区和主体区都放在**居中方形之内**（编译器按版式自动要求），直接出 2.35:1 横版，不走「方形母版再扩图」（扩图会把内容缩进中间、两侧留空）；方形版（次条、转发卡片）仍单独再出一张。合同要求的文字（C77 标题与影字，C90 标题、品牌名、系列标签）都要写进 `text.items` 并标 `role`，缺了编译直接报错。同一篇发到 X 时再出一张 16:9（`x-image`，1200×675）：版式不变，标题和主体离四边留足余量，因为 X 的信息流预览裁得更紧。
- 主标题加副标题两层。方形格式标题不超过 8 字（含空格和字母），副标题 8 到 14 字。
- 标题按画风气质写：水墨配「云海听松」，黏土配「小小早餐铺」，赛博配「夜城漫步」。不画方框和边框。

## 2 文章插图

- 每张归纳一段：判断句标题（写结论，不写话题）+ 3 到 5 个要点标签 + 一个结构，每个标签配一个具体物件。读者不看正文也知道这一段说了什么。
- 按内容形状选图型：对比（A 与 B、而不是）→ 左右对比、前后对比；序列（第一步、然后）→ 流程、时间线、路线；循环 → 飞轮；表面与原因 → 冰山；层级、优先级 → 金字塔、漏斗；由什么组成 → 中心辐射、便当格；一个关键数字 → 大数字；观点、金句 → 引语卡、概念隐喻。
- 横版 16:9（`article-summary`）放正文，适合并列关系；竖版 9:16（`article-summary-tall`）用于手机长图和转小红书，适合台阶、竖排卡片、时间线。一篇常见是横 3 竖 2。
- 推特单图版：同一结论再出一张 16:9，大标题、正好 3 个要点、右下角品牌标识；它会脱离正文单独传播。
- 标签只用原文里的真实术语和数字；隐喻画底层概念，不画字面物体。

## 3 小红书 + 微博（默认一组 6 张，3:4；张数与字数以 [scenes/xhs.md](scenes/xhs.md) 为准）

先按内容选组型，再套画风：

| 组型 | 页序 |
|---|---|
| 清单型 | 封面 → 一页看完 → 清单 1–2 → 清单 3–4 → 清单 5–6 或「最推荐」→ 总结卡 + 互动 |
| 教程型 | 封面（成品）→ 你需要什么 → 步骤 1–2 → 步骤 3–4 → 常见错误 → 总结卡 + 互动 |
| 测评对比型 | 封面（VS）→ 怎么比 → 对比 1 → 对比 2 → 按人群给结论 → 一张表 + 你选哪个 |
| 避坑型 | 封面（代价）→ 为什么会踩 → 坑 1–2（错 / 对成对）→ 坑 3–4 → 正确做法 → 打勾清单 + 互动 |
| 故事型 | 封面（有悬念的结果）→ 起点 → 转折 → 关键的两件事 → 变化 → 一条建议 + 互动 |
| 合集型 | 封面（X 个 / 一张图）→ 分类目录 → 分类 A → 分类 B → 分类 C → 速查卡 + 互动 |

- 第 2 页给继续滑的理由（目录、全貌或悬念），不复述封面；最后一页固定是能截图收藏的总结卡加一个互动问题。
- 封面类型：大字压顶、清单目录、对比 VS、手账拼贴、主角加大字、备忘录、问答气泡、合集索引。标题、内页、尾卡的字数按 [scenes/xhs.md](scenes/xhs.md) 第 6 步三档。
- 内页每页 30 到 90 字，每条不超过 22 字，每条带具体名词或数字。不用「最」「天花板」「闭眼入」。
- 先出封面，其余各页拿封面当参考图。微博九宫格会把封面和结尾裁成 1:1，这两页的主体和标题要居中。

## 4 PPT（16:9；下表是 12 种页型的写法示范，实际页数按 [scenes/ppt.md](scenes/ppt.md) 第 4 步页预算或用户给的页数）

| 页 | 写法 |
|---|---|
| 01 封面 | 大标题偏左、右侧主视觉、底部汇报人与日期 |
| 02 目录 | 左侧大字「目录」，右侧 3–4 个编号章节 |
| 03 章节页 | 巨大编号 + 章节名 + 一句引导，全套画风表现最强的一页 |
| 04 大数字 | 一个数字占画面三分之一，上方一句结论，下方一句说明 |
| 05 数据 | 结论标题 + 一张柱状图或表格 + 一个大数字解读 |
| 06 对比 | 两栏 + 中间 VS + 底部结论条 |
| 07 四象限 | 2×2，每格标题和一句要点 |
| 08 流程或时间线 | 4–5 个节点 |
| 09 图文论述 | 左 45% 插画，右 55% 标题和三条要点 |
| 10 金句 | 一句大字引语 + 出处 |
| 11 全幅图 | 整页氛围插画 + 一句短文字 |
| 12 谢谢观看 | 回扣封面 |

- 内容页标题写结论句（「午后是最大的增长机会」），不写话题词（「经营四象限」）。每页文字元素不超过 6 条，每条不超过 20 字。
- 场景页序：工作汇报用上表全部；课程教学多放流程和图文；产品发布多放大数字和对比；读书分享多放金句和全幅图；路演按「问题 → 方案 → 数据 → 团队 → 请求」。
- 先出封面，其余页拿封面当参考图。整页是图片，改字要单页重出；要可编辑文件时用 `sb.py pptx --mode illustration`（插画 + 可编辑文字）组装。

## 5 信息图（3:4）

11 种版式：流程、左右对比、层级金字塔、时间线、数据看板、便当格、冰山、循环、中心辐射、漏斗、2×2 矩阵。版式几何写在提示词前面，节点数写死；副标题明确写「不是一步，不编号」；矩阵逐格写明每个象限放什么，否则模型会放错格。

## 6 漫画

- 日漫混排页（`comic-mixed-page`）：讲故事；斜切格、跨格、人物破格、一个出血大格，从晨光到夕阳换光线。
- 四格（`comic-4panel`）：起承转合，每格换景别（大远景、中景、特写或俯拍、仰角），对白写进对应那一格的描述里，否则会挤到最后一格。
- 知识条漫（`comic-webtoon`）：学生加老师两个原创角色，用一个类比讲清一件事，最后一格是结论框。
- 每格写景别、场景、时间光线、动作表情；对白每格一两句，每句不超过 12 字；不让同一个人在同一个地方说四句话。

## 7 风格参考板

每个画风有一张风格参考板（色板、字体、材质、母题、构图、签名元素、气质），在选择器的画风详情里展示。

- 已有开源原作锚点的画风（38 个），出图时自动用原锚点，参考板只用于展示。
- 没有锚点的画风（34 个），参考板画成不含人物和动物的版本，登记为合同锚点，出图时自动当画风参考。画风参考板里如果有人物，会被串进每一张图（试点中 C30 的 PPT 几乎每页都出现参考板上的女孩和猫），所以当锚点的版本只画物件和风景。
- 一组图内部的一致性另靠「先出第一张，其余拿它当参考图」。用户自带 `role: style` 参考图时以用户的为准。
