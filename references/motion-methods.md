# 按图片的观看目的制作动态

先确定读者需要看见什么变化，再决定材料和动作。本页来自三张打磨图及三张冻结方法后的迁移图；样本小，用户采用另记。日常按本图用途读取对应小节和一个相关工程，不一次加载全部代码。完整可执行候选见 [三个工程示例](../examples/motion/README.md)，不要把示例构图套到所有图上。

## 开始前的三项判断

1. 用一句话写清动态收益，例如“看见灯源与河面反光相互呼应”“看清相册里两张完整照片”“顺着管道看懂雨水去向”。如果只能说“更生动”，先重做选图判断。
2. 查看原图和实际分件，列出固定内容、可动内容、支点、遮挡和缺件。漂亮照片可以保持整体，通过光路、纸页或解释层展开；不必先抠人物和物件。
3. 设计横向成片本身。审阅页在片外已经保留完整竖图，影片内不要机械重复一份“竖原图加局部”。只有解释关系确实需要时才并置总览与局部。主场景能合理横向取景时，让它占据主画面，保护完整人物及解释对象。

## 光影与氛围：变化发生在场景里

适合有明确灯源、受光面、雨幕、反射或天气层次的图。它表达时间和情境，不能只给整图加明暗蒙版。

先标注灯源和响应区，再按同一关系联动：窗内暖光对应窗边受光；桥灯对应水面反射；雨线落到街面后才有水圈。人物、建筑和画面中间调保持稳定。固定机位即可，反复放大缩小不会增加场景信息。

| 状态 | 要让观众看到 | 审片点 |
|---|---|---|
| 开始 | 原图的空间和正常曝光 | 主体可辨，暗部有细节 |
| 变化 | 真实位置的灯光、雨或反射 | 不穿过室内，不错移到人物上 |
| 响应 | 灯与反光、雨与地面有对应 | 变化可感知，不能压黑整片来夸大差异 |
| 停留与循环 | 看清场景后平稳接续 | 不让整城灯光无缘由地反复熄灭 |

例子的固定人物与局部光路可以借鉴，但城市切成多个视窗并不天然优于完整场景。没有可信的光路和响应区时，可改作完整照片展示，或保留静态。

## 相纸与展开：完整内容有观看时间

适合旅行记录、相册、印刷作品及纸张等具有明确平面的内容。照片与相纸是一个完整单元；人物不从照片里被截出，不能把缺头少脚当成“出框”。

先明确主照片、辅助照片及观看顺序，再选展开方法。页绕书脊、纸绕折线转动；照片从原位置移到有支撑的落位，接触阴影随位置变化。缺乏背面时不做翻背。合理取原图局部作为细节照片可以成立，但不要将同一个人重复成多人，或将风景撕成无法理解的碎片。

| 状态 | 要让观众看到 | 审片点 |
|---|---|---|
| 开始 | 物件原来在哪里 | 起点和承载面清楚 |
| 展开 | 整页或整张照片的行动 | 支点和遮挡连续，无截肢、穿纸 |
| 落定 | 完整内容成为主角 | 有足够停留，文字不抢画面 |
| 回收 | 沿同一物理关系归位 | 不以突然消失或任意弹跳代替收束 |

打磨相册时出现过“影片内部再次摆完整竖图，右侧再放同一相册”的重复构图。修订后让相册成为横向主体。这是构图判断，不是以后所有图都要改成相册。照片的轻微浮起也须有明确展示收益，不能只为满足“必须动”。

## 过程与解说：注意力沿真实连接前进

适合原文已有因果、路径、部件作用或前后关系的图。先核对知识和原图锚点，再画路径、高亮和短标签；步骤数取决于内容，不规定三步。物体可以固定，变化来自观众逐步看懂关系。

雨水图应核对屋面坡向、檐沟、落水管、桶口、龙头和软管；不能在屋面上任意折返。沙漏可解释上部储沙、细颈通过和下部累积；如果没有连续几何，就用明确的解释层，不能伪造摄影玻璃内部的大规模变形。

| 状态 | 要让观众看到 | 审片点 |
|---|---|---|
| 总览 | 整体对象和问题 | 解释对象完整，标签有留白 |
| 逐步 | 当前环节与原图位置对应 | 路径准确，不跨无关物体 |
| 连接 | 前一步怎样到下一步 | 隐藏环节不画成穿透路线 |
| 落定 | 完整关系可读 | 留出阅读时间，不用多段文字堆满画面 |

局部放大有明确解释收益时，可以和总览并置；放大框须能追溯到原图位置。标示和程序示意与原照片的真实状态分清，不把绘制效果冒称实际物理变化。

## 材料不足时改变制作路线

能由现有完整平面、真实支点、局部光路或准确解释层承担的，继续当前代码与分层流程。需要人物转身、鱼身弯曲、真实水浪持续形变时，先确认新姿态、关节、遮挡及时间连续性；刚性切片不能代替这些材料。确需补料时沿既有静态生图入口制作完整部件、背景或隐藏面，并记录实际来源。需要连续生成视频时转入视频制作流程，能力和接口必须实查，不因某个 Skill 名称就承诺已接通。

连续两轮仍不能修好同一结构问题时，换表达或保留静态。不要用更多粒子、装饰、缩放掩盖材料缺陷。

## 将一支样片变成可复用经验

先保存源图、实际素材、完整代码、导演稿及几个关键状态，再写适用条件、失败现象和修复依据。参考代码时改本图的锚点、比例、支点和节奏；不把示例路径坐标照搬到新图。联系表检查切边与遮挡，原尺寸帧检查曝光、路径与文字，连续至少两轮检查节奏与循环。技术通过、制作判断、用户采用、平台上传分别记录。

评估方法变化时，固定原图、模型、规格和每版预算上限，保留首稿及修订次数。先用少量图打磨，冻结方法后再做其他图；验证图在历史批次出现过就如实说明。不能把旧失败片当作新流程 A 版，也不能从少量样本推出普适胜率。

通过外部模型制作时，完整可执行交付优先，按本图加载所需方法和案例。输出中断、超出单次预算、确定性失败也算实际结果，不能悄悄重置首轮或无限提高额度。保留失败和余下额度，先缩小实现范围；补交仍计入本版调用次数。方案文字再完整，未交出可运行作品就仍是未完成。
