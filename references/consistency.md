# 从一而终：画风与角色贯彻 · 规格

> 状态：最小可用已实现（`scripts/stylebook/character.py`、`sb.py character`）。

## 用法

1. 写角色圣经 `character.json`：`id`（小写英文）、`name`、`desc`（一句外形概述）、`markers`（至少 3 条辨识特征，至少 2 条靠形状或标志物，如「头顶两个小圆发髻」「一枚月牙发夹」；只靠颜色的会被拒收，因为颜色会被样式色板改掉）。描述里不写具体的未成年年龄（如「12 岁」），写「年轻学生」「孩子」即可——带参考图改图时，具体年龄加儿童形象容易被服务方审核拦截（2026-09-25 实测同一场景连拦三次，去掉年龄当次通过）。
2. `python3 scripts/sb.py character sheet character.json --style C58` 出设定网格（正、侧、背全身 + 三种表情）。
3. 之后每张图的清单里写 `content.characters` 与 `references: [{"path": 设定网格, "role": "identity"}]`。
4. 出完几张后（背影等角度看不到的特征不算缺失；网格标签按应有文字比对） `python3 scripts/sb.py character check character.json 设定网格 图1 图2 … --style C58`：拼对照网格（第一格设定网格），独立看图逐条核对每条辨识特征。
5. 系列项目写 `stylebook.project.json`（`character.project_lock`）：风格码必须带修订号（如 `C58@r1`），合同升级时编译会拦下先问。

## 画风

锁定层原样贴 + 同一张锚点图 + 修订号锁定 + 系列圣经继承；系列中途合同升级不自动跟进，先问。批量计划可写 `"series": {"id": "项目内稳定 ID", "master_id": "正文图 ID"}` 指定母版；小红书、PPT、文章配图和绘本页会自动视为系列。混合封面与正文时优先正文作为母版，避免封面特殊构图支配正文。只有母版导出及独立看图均通过，后续图才引用其 raw 图；未验收或失败时后续项标记 `blocked`。参考图内容变化会让缓存失效。

## 参考图：三层，单次最多 3 张

参考图管说不清的「味道」（笔触、材质、色彩关系、造型语言）；文字管三件事：每张图只借什么不借什么、参考图没覆盖的内容怎么翻译成这个画风、硬禁项。一张参考图管得住味道，管不住「内容类型」，所以分三层：

1. **风格板**（每次都挂，排第 1）：无人物、无动物、无文字、无分格，只有色带、材质块、几个中性物件和一个小场景。长边 1024–1600 px（官方都没规定最低像素，低于 600 的笔触和纸纹传不过去；超过 2048 会被缩小），WebP。现有合同里的 `anchor` 就是这一层。
2. **内容范例**（按需挂 1 张）：合同 `exemplars[]` 里 `kind: character`（人物画法）或 `graphic`（图示画法）。清单要画人物就在 manifest 写 `"exemplars": ["character"]`；清单带 `structure`（信息图结构）自动挂图示范例。范例各自带隔离说明，只借画法，不借主体、姿势、服装、发色、背景和文字。
3. **系列母版**（运行时产生）：第 2 张起引用第 1 张通过验收的图，只引母版，不引上一张。

挂载规则由编译器保证：参考图总数 ≤ 3；装不下时范例直接不挂，不挤掉用户给的或系列母版；没有 `exemplars` 的合同提示词与以前逐字相同。选了色系时还会在最后自动附一张无字色带（`palette_swatch`，只取颜色），因为只写色值时模型平均色差约 11，给色块图后约 1。

**实验结论（2026-10-05，4 个画风、36 张）：** 新的无字风格板、再加内容范例，与现有锚点相比，在这些条件下没有观察到可见的串味或画风偏移差异，所以现有 72 张锚点不整批重做，内容范例默认不启用，只在某个画风被实测发现缺口时才为它配一张。无字风格板的出法（给没有合适锚点的新画风、或针对性重做用）：16:9，下缘一排五块柔边色块，其上三块材质样（纸或底、主笔触、细节纹理），中间四件日常物件（杯子、叶子、小房子、花盆）和一幅小风景或静物，无人物、无动物、无文字、无分格线，全部用该画风自己画出。

合同还可以写 `translation_rules`（人物、动物、水面金属玻璃、文字字形、图示怎么画，以及 `unsuitable` 写明本画风不适合的内容）和 `palette_spec`（5–7 个色块：名字、hex、作用、面积）。字段说明见 `styles/_schema/contract.schema.json`。

## 角色

- 角色圣经：外形靠形状与标志物区分（不能只靠颜色），做剪影测试。
- 一次生成整张设定网格（正、侧、背、表情），之后按景别配参考图。
- 属性隔离：每个角色的描述只写一次，多人画面给角色编号分工，或分别生成再合成。
- 改图就编辑定稿图，不重抽。

## 地点

- 分镜与连续场景先写地点圣经（固定陈设至少 3 条、光源方向和时段），出无人设定图，再以它为背景参考出定调图；之后每张都挂设定图作 `background` 参考。流程见 [scenes/storyboard.md](scenes/storyboard.md)。
- 同一场戏光源方向不变、不越轴；越轴必须写理由。

## 验收

逐条特征判断 + 一致性对照网格（第一格放定妆图）+ 重试上限；指标是每张可用图的平均重跑次数。
