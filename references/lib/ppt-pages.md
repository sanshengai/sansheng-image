# PPT 页型库与页规格卡

整页图片型 PPT 用。页数和阅读模式的算法在 [scenes/ppt.md](../scenes/ppt.md)；本页只列页型、选用信号、节奏和每页一张的规格卡。数字是建议值，待回测。

## 页型

结构页：封面、摘要页（总论点加支柱，放第 2 页）、议程页、章节过渡页、小结与行动页、结尾页（行动号召或值得记住的结论，不只是「谢谢」）、附录页。

内容页与选用信号：

| 页型 | 选用信号 | 骨架 |
|---|---|---|
| 论断加证据（默认） | 一条论断配一个例子、机制或一组数据；以下都不命中时用它 | 标题是断言；一个证据图；底部一行来源 |
| 大数字 | 一个数字是主角，带单位和比较基准 | 超大数字 + 一行解释与基准 |
| 数据图表 | ≥ 3 个同口径数据点要比较 | 数据先用代码画成真图当素材，模型只风格化外框，不凭文字画数 |
| 二元对比 | 相比、反之、前后、误区对正解 | 一个统一的场景被一条斜线分成两半，标题和两个标签写进画面 |
| 矩阵与表格 | ≥ 3 项在 ≥ 3 个维度上比较 | 行列标签要短；数值密集的表走精确排字 |
| 四象限 | 两个独立维度各分高低 | 十字坐标加四个象限命名 |
| 线性流程 | 首先、然后、第 N 步 | 左到右，4–7 个模块 |
| 循环机制 | 迭代、反馈、闭环 | 3–6 个环节加弯箭头 |
| 时间线 | ≥ 3 个带时间的事件 | 里程碑节点 |
| 层级与分类 | 分为几类、由几层构成 | 金字塔、树状或分层堆叠 |
| 并列要点卡片 | 3–4 个同构并列项 | 图标网格，每格一图标一短句 |
| 因果与漏斗 | 因为……所以；逐级收窄 | 因果链箭头或漏斗 |
| 概念解释 | 定义句或抽象机制 | 一个主隐喻图加 2–4 条旁注 |
| 案例与故事 | 有人物、时间、结果的具体例子 | 图文叙事；案例必须来自原文，不得编造 |
| 引言页 | 直接引语，带出处 | 一句大字引语加署名 |
| 警示与误区 | 但是、风险、陷阱 | 聚焦一个风险，不堆条目 |
| 全幅图 | 情绪点、转折、信息量低 | 满版图，文字极少，作呼吸页 |

选用决策顺序（命中即停）：结构页位置 → 大数字 → ≥ 3 个同口径数值（数据图表）→ 文字表格（矩阵）→ 二元对立（对比）或两个正交维度（四象限）→ 有序依赖（流程）或循环 → 带时间事件（时间线）→ 层级分类 → 同构并列 → 因果、定义、案例、引语、风险 → 情绪转折（全幅图）→ 都不命中（论断加证据）。

## 关键页的必须 / 可选 / 禁止

| 页 | 必须 | 可选 | 禁止 |
|---|---|---|---|
| 封面 | 一句话标题（说清讲什么，不只写话题词）；汇报人或机构；日期 | 副标题一行；一个主视觉；用户给的 Logo | 目录、要点列表、页码；模型自画 Logo |
| 目录 / 议程 | 3–5 个章节，与章节过渡页逐字一致 | 每章一句话说明；当前进度标记 | 超过 6 项；章节名与正文标题对不上 |
| 章节过渡 | 章节编号与章节名；一句引导 | 本章要回答的问题 | 正文内容、数据、超过 2 行字 |
| 数据页（大数字 / 图表） | 数字带单位与比较基准；数据来源一行；图表由代码画成真图当素材 | 一句解读；高亮一个关键数 | 模型凭文字画数；同一页超过一个主图；没有出处的数字 |
| 收尾 | 一句行动号召或值得记住的结论；需要拍板时写清请求与选项 | 联系方式；下一步时间点 | 只写「谢谢」；新论点或新数据 |

## 节奏

- 相邻两页页型不同；同一页型在连续 8 页里不超过 2 次。
- 每页标节奏：anchor（结构页）、dense（信息密集）、breathing（低密度停顿）。连续 dense 不超过 3 页后放一页 breathing；呼吸页不放 ≥ 3 张卡片的网格。
- 每章开头用 anchor 页；大数字页与引言页不连续出现。

## 页规格卡（每页一张，文字真源）

每页一份 JSON，出图提示词只从它生成：

```json
{
  "n": 7, "role": "content", "claim_id": "C2.1", "type": "compare", "rhythm": "dense",
  "title": "断言句",
  "rendered_text": [{"role": "title", "text": "…"}, {"role": "label", "text": "…"}],
  "forbid_render": ["色值", "页码"],
  "text_mode": "baked | plate_overlay",
  "must_keep": ["37.2%", "2023 年"],
  "source_refs": ["第 2 节第 4 段"],
  "notes": "讲者备注，不进画面"
}
```

硬规矩：`rendered_text` 是唯一允许出现的文字，写进提示词的必须与它逐字一致；内部约束放 `forbid_render`，不得混进可见文字；文字承载方式（整页烘焙或无字底图叠字）在设计阶段逐页声明，不事后覆盖修补。

## 整套一致性

风格块（背景质地、字体观感、带色值的 3–4 种颜色、禁用清单）全套每页原样带上；先出 3 张样张（封面、最复杂的内容页、最简单的内容页），过目通过后锁定风格块再批量；第一张内容页当后续页的参考图（封面不当参考，因为封面构图特殊）；风格块一改，全套旧验收作废。

## 讲者备注

从规格卡生成，不从图片猜；每句口头一口气说完（约 35 汉字内）；A 页最后一句抛出 B 页要回答的问题，过渡不做回顾；不复述画面上的字；润色时锁定限定词和数字；阅读式的备注放来源位置和补充，不是演讲稿。

## 单页重做

用户说「第 7 页重做」时只动这一页：

1. 只改这一页的规格卡（标题、文字、页型或画面），改完跑 `sb.py deck check` 确认整套节奏仍合格（换页型可能破坏相邻规则）。
2. 重出时带上同一个风格块，并把第一张内容页当参考图；风格块没变，其他页的验收照样有效。
3. 只是改字：L0 改规格卡后单页重出；L1 无字底图加叠字。
4. 要可编辑的整页对象，交给专门的 PPT 工具，本 Skill 不做。

用户要的改动涉及风格块（换色、换字体观感）时，说明这会让全套旧验收作废、需要整套重出，问一次再做。
